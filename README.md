# VALUEX — Маркетплейс спортивной аналитики и разовых прогнозов

Готовый коммерческий веб-продукт для **разовой и пакетной продажи отдельных спортивных прогнозов** (без навязанных VIP-подписок и автосписаний) с верифицированной статистикой, приемом оплат через **ЮKassa API v3 (54-ФЗ)**, автоанонсами в **Telegram-канал**, личным кабинетом покупателя, партнерской программой и изолированной админ-панелью.

## Ключевые возможности v4 (Маркетплейс + Российский ИИ-Автопилот 24/7)

- **Автономный модуль «ИИ-Автопилот 24/7» (`/admin` → ИИ-Автопилот)**:
  - **Прямой бесплатный сбор российской линии (`0 ₽/мес`, без зарубежных спортивных ключей)**: с российского IP сервера автоматически работает 4-уровневый каскад **Фонбет РФ → Леон РФ → Международный Матч-центр (с русской локализацией клубов) → Встроенный резерв** с жестким фильтром мусорных рынков (угловых, ЖК, кибер-симуляций и молодежных лиг).
  - **ИИ-аналитик по API**: выбор в 1 клик между **DeepSeek API** (работает из РФ без VPN), **OpenRouter** (Claude / GPT-4o / Qwen / DeepSeek), **OpenAI** или встроенным математическим аналитиком без внешних ключей, плюс кнопка **«Диагностика узлов»** в реальном времени.
  - **Два режима работы + трекер дистанции ИИ**: отдельный подсчет `Yield %`, `Winrate %` и чистого профита именно по прогнозам алгоритма. Можно работать через **«Премодерацию черновиков»** или включить тумблер **«Полный автопилот 24/7»** — система сама выпускает утреннюю (`09:00 МСК`) и вечернюю (`18:00 МСК`) линию с `SHA-256` и анонсами в Telegram, а после финального свистка сама сверяет официальный счет, рассчитывает `WIN / LOSS / PUSH` и начисляет страховку на баланс покупателям.
- **Никаких подписок и автосписаний**: покупатель приобретает только выбранные им матчи поштучно (`PAID_SINGLE`) либо собирает **Пакет событий** кнопкой `«+ В пакет»` с автоматической скидкой **−15%** (за 2 события) и **−25%** (за 3+ событий).
- **Промокоды на скидку**: встроенная проверка промокодов прямо в окне оплаты (стартовый промокод `START15`) и выпуск новых промокодов для Telegram-акций из админ-панели.
- **Страховка 100% на баланс при минусе**: события со знаком `«Страховка 100% на баланс»` автоматически возвращают оплаченную стоимость на внутренний кошелек покупателя при расчете исхода как `LOSS` или `PUSH`.
- **Честная верификация SHA-256 и серверная защита**: секретный исход, коэффициент и аналитический текст никогда не передаются в JSON до оплаты или финального свистка, а неизменность прогноза фиксируется SHA-256 отпечатком до начала встречи.
- **Калькулятор флэт-дистанции в рублях**: интерактивный пересчет доходности верифицированной истории под рабочий банк игрока (`30k` – `500k ₽`) на странице `/stats`.
- **Живые OpenGraph-превью для Telegram/VK**: каждая персональная страница матча `/predictions/[slug]` отдает мета-карточку с командами, турниром и рекомендуемым флэтом.

## Дизайн и структура страниц

Контрастная журнальная палитра (`#F4F6FA` светлый фон + `#0B0F19` акцентные темные блоки + королевский синий `#2563EB`) и сетка маркетплейса по **3 карточки событий в ряд**:

- `/` — Главная витрина: контрастный блок с «Главным событием дня», верифицированные показатели (`Yield`, `Чистый профит`, `Проходимость`, `Средний кэф`), сетка актуальных событий с монограммами команд и сборкой пакета, график `Equity Curve` и блок последних расчетов.
- `/predictions` — Каталог всех актуальных событий и открытого архива с фильтрами (`Актуальная линия`, `Со страховкой 100%`, `Бесплатные разборы`, `Архив результатов`), поиском и корзиной пакета.
- `/predictions/[slug]` — Персональная страница конкретного матча с OpenGraph-разметкой.
- `/stats` — Верифицированная статистика (`7 дней` / `30 дней` / `За всё время`), калькулятор банка в рублях и открытый реестр SHA-256 проверки.
- `/login` и `/register` — Регистрация и вход по email/паролю (`scrypt` + подписанные `HttpOnly` cookie-сессии).
- `/cabinet` — Личный кабинет покупателя и партнера: сетка купленных прогнозов, кошелек со страховыми возвратами, история чеков и реферальная ссылка `?ref=`.
- `/payment/return` — Автоматическая сверка статуса платежа после возврата с формы ЮKassa.
- `/legal/offer` и `/legal/privacy` — Публичная оферта (включая условия страховки на баланс) и Политика обработки ПДн (152-ФЗ).
- `/admin` — Закрытая панель управления владельца: публикация событий с пресетами турниров и страховкой, изменение цены в 1 клик, расчет матчей с автоначислением страховки, управление пакетными скидками и промокодами, ключи ЮKassa и Telegram-бота.

## Быстрое обновление уже установленного сервера Reg.ru

```bash
cd /opt/Stavki_na_sport && git fetch origin && git pull --ff-only && bash deploy/update-regru.sh
```

Скрипт автоматически определяет PM2 или Docker Compose по установленному приложению; при необходимости режим можно указать явно: `bash deploy/update-regru.sh --pm2` или `bash deploy/update-regru.sh --docker`. Для PM2 корневой `.env` и `frontend/.env.local` синхронизируются; для Docker источником конфигурации служит корневой `.env`. Обновление завершается только после успешного `/api/health`.

Для установки в Docker Compose используйте `bash deploy/install-regru.sh --docker`. Установка без параметра использует PM2.

### Хранилище и сбои

- В production используйте PostgreSQL и настроенный `DATABASE_URL`. Если PostgreSQL недоступна, приложение **не переключается** на отдельный локальный JSON: чтение и записи отклоняются, `/api/health` возвращает 503. После восстановления соединение проверяется повторно; не удаляйте `DATABASE_URL` как способ обхода сбоя.
- Локальный файл без `DATABASE_URL` предназначен для разработки и одного процесса, не синхронизируется с PostgreSQL и не является её резервной копией. В production такой режим отмечается в healthcheck как проблемный. Файл с ошибкой чтения, некорректным JSON или отсутствующими ключевыми разделами не заменяется автоматически пустой базой; проверьте и восстановите резервную копию.
- Ошибка при записи или потеря ответа не доказывает, что операция не выполнена: перед повтором проверьте заказы, баланс и платежи. При недоступном хранилище webhook ЮKassa отвечает 503; по [документации ЮKassa](https://yookassa.ru/developers/using-api/webhooks) неподтверждённые уведомления повторяются не более 24 часов. После длительного сбоя необходима ручная сверка в личном кабинете ЮKassa.

## Установка с нуля на чистый VPS Reg.ru Cloud (Ubuntu 22.04 / 24.04 / 26.04 LTS)

```bash
apt update && apt install -y git
git clone https://github.com/gjjut/Stavki_na_sport.git /opt/Stavki_na_sport
cd /opt/Stavki_na_sport
bash deploy/install-regru.sh
```

### Привязка домена и бесплатный HTTPS SSL (для боевой ЮKassa)
Направьте A-запись вашего домена на IP сервера в Reg.ru и выполните одну команду:
```bash
cd /opt/Stavki_na_sport && bash deploy/setup-domain-ssl.sh ваш-домен.ru ваш@email.ru
```
Скрипт сам настроит Nginx, выпустит бесплатный сертификат Let's Encrypt с автопродлением и выведет готовый адрес Webhook для личного кабинета ЮKassa. Ежедневные резервные копии PostgreSQL сохраняются автоматически в `/var/backups/valuex/` в режимах PM2 и Docker Compose.

### Стартовый вход администратора
- Страница входа: `/login`.
- Установщик создаёт случайный пароль администратора и выводит его один раз в конце установки. Сохраните его в менеджере паролей; постоянного пароля в репозитории нет.
- Логин берётся из `ADMIN_EMAIL` (по умолчанию установщика — `admin@valuex.pro`). После входа задайте свой пароль длиной не менее 12 символов в `/admin` → «ЮKassa, Telegram и Бренд».
- Для production обязательны уникальные `SESSION_SECRET` и `AUTOPILOT_CRON_SECRET` длиной не менее 32 символов. Установщик генерирует их автоматически; не публикуйте `.env` и не коммитьте секреты.
