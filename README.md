# VALUEX — Маркетплейс спортивной аналитики и разовых прогнозов

Готовый коммерческий веб-продукт для **разовой продажи отдельных спортивных прогнозов** (без навязанных VIP-подписок и автосписаний) с верифицированной статистикой, приемом оплат через **ЮKassa API v3 (54-ФЗ)**, автоанонсами в **Telegram-канал**, личным кабинетом покупателя, партнерской программой и изолированной админ-панелью.

## Дизайн и структура страниц

Контрастная журнальная палитра (`#F4F6FA` светлый фон + `#0B0F19` акцентные темные блоки + королевский синий `#2563EB`) и сетка маркетплейса по **3 карточки событий в ряд**:

- `/` — Главная витрина: контрастный блок с «Главным событием дня», ключевые верифицированные показатели (`Yield`, `Чистый профит`, `Проходимость`, `Средний кэф`), сетка актуальных событий 3×2, график `Equity Curve` и блок последних расчетов.
- `/predictions` — Каталог всех актуальных событий и открытого архива с фильтрами по видам спорта, формату (платные / бесплатные) и поиском.
- `/predictions/[slug]` — Персональная страница конкретного матча.
- `/stats` — Верифицированная статистика (`7 дней` / `30 дней` / `За всё время`), разрез по дисциплинам и открытый реестр SHA-256 проверки.
- `/login` и `/register` — Регистрация и вход по email/паролю (`scrypt` + подписанные `HttpOnly` cookie-сессии).
- `/cabinet` — Личный кабинет покупателя и партнера: сетка купленных прогнозов, кошелек для покупок в 1 клик, история чеков, генератор `?ref=` ссылок и вывод реферальных средств.
- `/payment/return` — Автоматическая сверка статуса платежа после возврата с формы ЮKassa.
- `/legal/offer` и `/legal/privacy` — Публичная оферта на разовые информационные услуги и Политика обработки ПДн (152-ФЗ).
- `/admin` — Закрытая панель управления владельца (публикация событий с индивидуальной ценой, закрепление «Главного события дня», расчет матчей в 1 клик, CRM покупателей, возвраты, партнерские выплаты, ключи ЮKassa и Telegram-бота).

## Быстрое обновление уже установленного сервера Reg.ru

```bash
cd /opt/Stavki_na_sport && git pull && bash deploy/update-regru.sh
```

## Установка с нуля на чистый VPS Reg.ru Cloud (Ubuntu 22.04 / 24.04 / 26.04 LTS)

```bash
apt update && apt install -y git
git clone https://github.com/gjjut/Stavki_na_sport.git /opt/Stavki_na_sport
cd /opt/Stavki_na_sport
bash deploy/install-regru.sh
```
