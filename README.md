# VALUEX.PRO — Коммерческая платформа спортивной аналитики (v2)

Полноценный готовый веб-продукт для продажи спортивных прогнозов и VIP-подписок с верифицированной статистикой, приемом оплат через **ЮKassa API v3 (54-ФЗ)**, автоинвайтами в **закрытый Telegram-канал**, личным кабинетом клиента, реферальной системой и изолированной админ-панелью.

## Структура страниц продукта

### Клиентская витрина и личный кабинет
- `/` — Главная страница (оффер, верифицированные показатели Yield / Win Rate, ближайшие матчи, график Equity Curve, тарифы VIP).
- `/predictions` — Полная лента предстоящих/LIVE прогнозов и открытый архив рассчитанных встреч с фильтрацией по видам спорта.
- `/predictions/[slug]` — Отдельная страница матча (для прямых ссылок из Telegram и индексации).
- `/stats` — Верифицированная статистика за 7 / 30 дней и всё время, разрез по дисциплинам и реестр криптографической проверки SHA-256.
- `/tariffs` — Сравнение тарифов VIP (`7 дней`, `30 дней`, `Навсегда`) и ответы на частые вопросы.
- `/login` и `/register` — Регистрация и вход по email/паролю (`scrypt` + подписанные `HttpOnly` сессии).
- `/cabinet` — Личный кабинет покупателя и партнера (купленные прогнозы, приглашение в закрытый Telegram-канал, пополнение баланса, калькулятор флэта под личный банк, генератор `?ref=` ссылок и вывод реферальных средств).
- `/payment/return` — Страница автоматической сверки статуса платежа после возврата с формы оплаты ЮKassa.
- `/legal/offer` и `/legal/privacy` — Публичная оферта и Политика обработки персональных данных (152-ФЗ) с динамической подстановкой реквизитов продавца (обязательно для модерации ЮKassa).

### Закрытая панель управления (`/admin`)
Доступна строго после входа под учетной записью с ролью `ADMIN` (обычные посетители не видят никаких кнопок управления):
1. **Сводка бизнеса** — Выручка, активные VIP-подписки, клиентская база, общий Yield.
2. **Прогнозы и расчет** — Публикация новых прогнозов с жесткой фиксацией коэффициента (SHA-256) + автопуш в VIP-канал Telegram + расчет в 1 клик (`Выигрыш`, `Проигрыш`, `Возврат`, `Cashout`).
3. **Клиенты (CRM)** — Поиск пользователей, выдача промо-VIP (`+7д`, `+30д`), начисление бонусного баланса, блокировка.
4. **Тарифы и оплаты** — Редактирование цен подписок и ординаров прямо из браузера + журнал платежей с функцией возврата.
5. **Партнеры и выплаты** — Воронка по всем `?ref=` ссылкам и обработка заявок партнеров на вывод (`СБП`, `Карта РФ`, `USDT TRC-20`).
6. **ЮKassa, Telegram и реквизиты** — Переключение тестового/боевого режима ЮKassa, ввод `Shop ID` и секретного ключа, ввод токена Telegram-бота с кнопкой проверки канала, реквизиты ИП/Самозанятого и смена пароля администратора.

## Быстрое обновление уже установленного сервера Reg.ru

Если сервер уже развернут в `/opt/Stavki_na_sport`:

```bash
cd /opt/Stavki_na_sport && git pull && bash deploy/update-regru.sh
```

## Установка с нуля на чистый VPS Reg.ru Cloud (Ubuntu 22.04 / 24.04 / 26.04 LTS)

```bash
apt update && apt install -y git
git clone https://github.com/gjjut/Stavki_na_sport.git /opt/Stavki_na_sport
cd /opt/Stavki_na_sport
bash deploy/install-regru.sh
```
